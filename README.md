# Витте-Дашборд — модуль визуализации данных

Веб-приложение для единого центра статистических данных ЧОУ ВО «Московский университет им. С.Ю. Витте».
Забирает показатели из «1С:Предприятие» (HTTP-сервис), сохраняет их в PostgreSQL и показывает в виде
интерактивных дашбордов и отчётов с разграничением прав по ролям.

**Автор:** Новоселов Антон Андреевич  
**Тема ВКР:** «Разработка модуля визуализации данных для единого центра статистических данных с интеграцией в 1С:Предприятие»  
**Репозиторий:** https://github.com/AntoshkaSRE/vitte

## Возможности

- 15 публичных страниц (главная, о модуле, показатели, факультеты, направления, открытая статистика, новости, FAQ, документация, контакты с формой обратной связи и др.), меню из 11 пунктов, «хлебные крошки» на каждой странице, ФИО автора в подвале;
- 5 дашбордов (до 5 виджетов на панель): столбчатые, линейные, круговые диаграммы, KPI; фильтры по периоду и факультету; экспорт диаграмм в PNG, печать в PDF;
- отчёты в форматах XLSX, DOCX, CSV (успеваемость по группам, сводные показатели);
- 4 роли: Администратор, Руководство, УМУ, Деканат (деканат видит только свой факультет);
- панель администратора (10 страниц): пользователи, факультеты, показатели, новости, обращения, интеграция с 1С, журнал аудита;
- личный кабинет (6 страниц): обзор, профиль, смена пароля, история отчётов, личные файлы, настройки;
- интеграция с 1С: загрузка JSON-выгрузки по HTTP или из файла-эмулятора `data/onec_export.json`, журнал синхронизации, кэш агрегатов (TTL 1 час);
- адаптивный интерфейс (ПК, планшет, смартфон), светлая и тёмная темы.

## Технологии

Python 3.12, Flask 3.1, PostgreSQL 17 (драйвер psycopg 3), Chart.js 4, openpyxl, python-docx, pytest.
Обоснование выбора библиотек приведено в пояснительной записке.

## Установка и запуск

```powershell
# 1. Клонировать репозиторий и создать виртуальное окружение
git clone https://github.com/AntoshkaSRE/vitte
cd vitte
python -m venv .venv
.venv\Scripts\activate              # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

# 2. Настроить подключение к PostgreSQL
copy .env.example .env              # при необходимости изменить DATABASE_URL

# 3. Создать базу, схему и загрузить тестовые данные
python tools/init_db.py

# 4. Запустить приложение
python main.py                      # откроется на http://127.0.0.1:5000
```

Файлы базы данных находятся в каталоге `sql/`: `create_tables.sql` (схема, 20 таблиц),
`insert_test_data.sql` (тестовые данные), `vitte_dump.sql` (полная выгрузка pg_dump).

## Размещение на бесплатном хостинге

В репозитории подготовлены `Procfile` и `render.yaml` для сервиса Render (бесплатный тариф:
веб-сервис и PostgreSQL). Порядок: создать Blueprint из репозитория → после сборки выполняется
`python tools/init_db.py`. Ссылка на развёрнутый ресурс указывается во введении к ВКР.

## Интеграция с 1С

Формат ответа HTTP-сервиса 1С:

```json
{"values": [{"indicator": "STUDENTS_TOTAL", "period": "2026/2027-1", "faculty": "FIT", "value": 380}]}
```

Адрес сервиса задаётся в панели администратора («Интеграция с 1С») или переменной `ONEC_URL`.
Если адрес пуст, используется файл `data/onec_export.json`. Готовое решение на стороне 1С —
HTTP-сервис конфигурации, возвращающий выборку из регистров статистики в указанном формате.
