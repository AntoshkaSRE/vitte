# Баг-репорты Витте-Дашборд

Шкала серьёзности: S1 Блокирующая, S2 Критическая, S3 Значительная, S4 Незначительная, S5 Тривиальная.
Приоритет: высокий / средний / низкий. Все дефекты найдены 23.11.2026 при тестировании сборки `master`.

## BUG-001. Главное меню переносится на вторую строку
| Атрибут | Значение |
|---|---|
| Серьёзность | S5 — Тривиальная |
| Приоритет | Низкий |
| Окружение | Chromium, окно 1180 px и шире |
| Шаги | 1. Открыть любую страницу на ПК |
| Фактический результат | Пункт «Контакты» отображается отдельной строкой под остальными пунктами |
| Ожидаемый результат | 11 публичных пунктов умещаются в одну строку |
| Статус | Исправлен: уменьшены отступы и шрифт пунктов меню (коммит «Меню в одну строку…») |

## BUG-002. Деканат без привязки к факультету видит данные всех факультетов
| Атрибут | Значение |
|---|---|
| Серьёзность | S2 — Критическая (нарушение разграничения доступа) |
| Приоритет | Высокий |
| Шаги | 1. Администратор создаёт пользователя с ролью «Деканат» без факультета 2. Войти под ним 3. Открыть `/api/dashboard/contingent` |
| Фактический результат | В ответе данные всех 5 факультетов |
| Ожидаемый результат | Данных нет (пользователь не привязан ни к одному факультету) |
| Причина | `faculty_scope()` возвращал `None` при пустом `faculty_id`, что означало «без ограничений» |
| Статус | Исправлен: возвращается несуществующий идентификатор (-1). Тест `test_bug002_dean_without_faculty_sees_nothing` |

## BUG-003. Администратор может изменить собственную роль
| Атрибут | Значение |
|---|---|
| Серьёзность | S3 — Значительная |
| Приоритет | Средний |
| Шаги | 1. Войти под `admin` 2. Открыть «Изменить» для себя 3. Выбрать роль «УМУ», сохранить |
| Фактический результат | Роль изменена, администратор теряет доступ к панели; система может остаться без администратора |
| Ожидаемый результат | Сообщение «Нельзя изменить собственную роль…», изменения не сохраняются |
| Статус | Исправлен. Тест `test_bug003_admin_cannot_remove_own_admin_role` |

## BUG-004. Открытое перенаправление в кнопке «Обновить данные»
| Атрибут | Значение |
|---|---|
| Серьёзность | S3 — Значительная (уязвимость безопасности) |
| Приоритет | Средний |
| Шаги | 1. Войти 2. Отправить POST `/dashboards/refresh` с `back=https://evil.example.com/` и корректным CSRF-токеном |
| Фактический результат | Ответ 302 с `Location: https://evil.example.com/` |
| Ожидаемый результат | Перенаправление только на внутренние адреса сайта |
| Статус | Исправлен: общая функция `safe_target` (разрешены только пути, начинающиеся с `/`). Тест `test_bug004_refresh_open_redirect` |

## BUG-005. Личные настройки (период, тип графика) не применяются
| Атрибут | Значение |
|---|---|
| Серьёзность | S3 — Значительная (часть логики работает некорректно, есть обходной путь) |
| Приоритет | Средний |
| Шаги | 1. В кабинете → «Настройки» выбрать период «Осенний семестр 2023/2024», тип графика «Круговая» 2. Открыть дашборд |
| Фактический результат | Выбран последний период, столбчатые диаграммы не меняются |
| Ожидаемый результат | Период по умолчанию из настроек; столбчатые диаграммы заменяются выбранным типом |
| Статус | Исправлен: `resolve_filters` учитывает настройки, `loadDashboard` получает предпочитаемый тип. Тест `test_bug005_default_period_from_settings_is_applied` |
