# Руководство пользователя Витте-Дашборд

Адрес работающего сайта: https://vitte.onrender.com. Учётные записи для проверки указаны в `README.md`.

## Общие сведения

- Публичные страницы (главная, показатели, факультеты, новости и др.) доступны без входа.
- Для дашбордов, отчётов, личного кабинета и администрирования нужен вход: кнопка **Войти** в шапке.
- После пяти неудачных попыток входа за пять минут вход для этого логина временно блокируется.
- Сессия действует 8 часов; кнопка **Выйти** завершает её досрочно.
- Переключатель светлой и тёмной темы находится в разделе **Личный кабинет → Настройки**.

## Роли и доступ

| Роль | Дашборды | Отчёты | Администрирование |
|---|---|---|---|
| Деканат | только свой факультет | да | нет |
| УМУ | все факультеты | да | нет |
| Руководство | все, включая сводные | да | нет |
| Администратор | все | да | да |

## Дашборды

1. Откройте раздел **Дашборды** и выберите панель.
2. Выберите период и факультет в фильтрах (деканату факультет подставляется автоматически).
3. Диаграмму можно сохранить как PNG, страницу — распечатать или сохранить в PDF (при печати меню и формы скрываются).
4. Кнопка обновления сбрасывает кэш агрегатов; без неё данные обновляются не реже раза в час.

## Отчёты

В разделе **Отчёты** выберите тип отчёта, период, факультет и формат (XLSX, DOCX или CSV). Сформированный файл скачивается
сразу и сохраняется в **Личный кабинет → История отчётов**.

## Личный кабинет

| Страница | Что можно сделать |
|---|---|
| Обзор | сводка по учётной записи и последним действиям |
| Профиль | изменить ФИО и e-mail |
| Смена пароля | пароль от 8 символов, буквы и цифры или символы, не равен логину и не из списка частых |
| История отчётов | повторно скачать ранее созданные файлы |
| Файлы | загрузить (до 5 МБ: xlsx, docx, csv, pdf, png, jpg, txt), скачать, удалить |
| Настройки | период и тип диаграммы по умолчанию, тема оформления |

## Панель администратора

| Страница | Назначение |
|---|---|
| Сводка | общие счётчики системы |
| Пользователи | создание, редактирование, блокировка, сброс пароля (свою роль и блокировку изменить нельзя) |
| Факультеты | справочник факультетов, направлений и кафедр |
| Показатели | справочник показателей и единиц измерения |
| Новости | публикация и скрытие новостей |
| Обращения | сообщения из формы обратной связи |
| Интеграция с 1С | синхронизация выгрузки и журнал загрузок |
| Аудит | журнал действий пользователей с фильтром и кнопкой **Скачать CSV** |

## Если что-то не работает

- Страница `/healthz` показывает, доступна ли база данных (`ok` или `error`).
- На бесплатном хостинге первое обращение после простоя занимает до минуты: сервис «просыпается».
- Ошибка 403 означает, что у вашей роли нет доступа к странице; 404 — страницы не существует.
